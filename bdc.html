How to read it

Built from the SEC’s BDC Data Sets with code anyone can rerun.

The observed BDC book, not all AI debt.Most AI-infrastructure debt sits with private funds, banks, insurers and project bonds that file no schedules. This is the slice that does.
Facts, not scores.Every number is the BDC’s own filing, linked. No stress score is given to any named company. A mark is the lender’s opinion, and it lags the market.
Matched by name, signed off.Holdings are matched to borrowers by legal name and signed off by a maintainer. Hyperscale data-center developers are shown apart from neoclouds. The register, review log and code are in the open lab; challenge any row there.
