# AI Credit Stress Index (ACSI)

This repo holds the static site for the AI Credit Stress Index, a weekly reading of where the stress in AI infrastructure sits: in the debt that financed the build-out, or in what the GPUs earn.

## What's in it

- `index.html` is the page. It does all the scoring in the browser using method v0.1, and draws:
  - the headline gap
  - "The flip", a month-by-month reconstruction from dated prices
  - the gap translated into H100 rent
  - the CDS and H100 charts
  - the borrower price ladder
  - the inputs, events, unknowns and method sections
- `data.js` holds this edition's data. It's generated by `build/make_data.py` from the files in `build/`.
- `api/gpu.js` is a Vercel serverless function behind `/api/gpu`. It returns live H100 asking prices from public GPU marketplaces (Akash and RunPod; Vast.ai too if `VAST_API_KEY` is set). The "Live H100 asking price" card stays hidden whenever the function returns nothing usable.
- `e/<as-of date>/` holds a frozen copy of each edition, which is what the permanent link and the "cite this" line point to.
- `og.png` is the 1200×630 image used for link previews.

## Deploy

There's no build step. On Vercel, import the repo, set the framework preset to "Other" and leave the build and output settings empty. The `api/` folder is picked up as a serverless function automatically.

Optional environment variables: `VAST_API_KEY`, `RUNPOD_API_KEY`.

## Weekly update

1. Update the files in `build/` and run `python3 build/make_data.py`.
2. Copy `index.html` and `data.js` into `e/<new as-of date>/`.
3. Push.

Levels come from press reports and public index pages, and each one links to its source. This is not investment advice.
