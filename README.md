# AI Credit Stress Index (ACSI)

Live at **https://aistress.si** (also served at ai-credit-stress-index.vercel.app).

This repo holds the static site for the AI Credit Stress Index, a weekly reading of where the stress in AI infrastructure sits: in the debt that financed the build-out, or in what the GPUs earn.

## What's in it

- `index.html` is the page. It does all the scoring in the browser using method v0.1, and draws:
  - the headline gap
  - "The flip", a month-by-month reconstruction from dated prices
  - the gap translated into H100 rent
  - the CDS and H100 charts
  - the borrower price ladder
  - the inputs, events, unknowns and method sections
- `data.js` holds this edition's data. It's generated by `build/make_data.py` from the files in `build/`.
- `api/` holds Vercel serverless functions that feed the LIVE board. Every card stays hidden whenever its function returns nothing usable.
  - `api/cds.js` (`/api/cds`): daily 5-year CDS levels for Oracle, CoreWeave and Meta. They come from single-name CDS trades that DTCC publishes free under the SEC's swap-reporting rules (pddata.dtcc.com). Upfront prices are converted to spreads with a flat-hazard model.
  - `api/live.js` (`/api/live`):
    - Polymarket's "CoreWeave announces bankruptcy by…" odds ladder.
    - Pendle's PT-sUSDai implied rate (USD.AI's GPU-loan vault) minus SOFR from the NY Fed, which is the onchain GPU credit spread.
    - Hyperliquid HIP-3 24/7 perps on CoreWeave, Nebius, IREN, Cipher, Oracle and Nvidia.
  - `api/gpu.js` (`/api/gpu`): live H100 asking prices from public GPU marketplaces. Akash and RunPod need no key; Vast.ai is used only if `VAST_API_KEY` is set.
  - `api/tape.js` (`/api/tape`): the latest single-name CDS trades from DTCC's public real-time ticker, AI-infrastructure names flagged; the page polls it every 20 seconds. The page also polls Hyperliquid's public price feed directly every 4 seconds for the perps. Nothing on the page is interpolated or simulated.
  - `api/og.js` (`/api/og`): the 1200×630 share card (PNG), drawn with satori and resvg from the weekly reading plus live context. It is the site's `og:image`; if it fails it redirects to the static `og.png`.
  - `api/share.js` (`/s/<stamp>`, via the rewrite in `vercel.json`): a small page whose link preview is the live card, then redirects to the index. Each share gets a new stamp, so X and LinkedIn fetch a fresh card.
  - Files in `api/` starting with `_` are helpers and fonts (Inter and JetBrains Mono, SIL Open Font License), not routes.
- `e/<as-of date>/` holds a frozen copy of each edition, which is what the permanent link and the "cite this" line point to.
- `og.png` is the 1200×630 image used for link previews.

## Deploy

There's no build step. On Vercel, import the repo, set the framework preset to "Other" and leave the build and output settings empty. The `api/` folder is picked up as a serverless function automatically.

Optional environment variables: `VAST_API_KEY`, `RUNPOD_API_KEY`.

## Weekly update

1. Update the files in `build/` and run `python3 build/make_data.py`.
2. Copy `index.html` and `data.js` into `e/<new as-of date>/`.
3. Push.

Levels come from press reports and public index pages, and each one links to its source. This is not investment advice.
